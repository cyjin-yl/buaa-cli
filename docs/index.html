BUAA CLI

A Rust command line for BUAA workflows, with structured output and conservative request control.

Know the boundary. Timed-input replay, archive lookup/capture and the authoritative teaching/research organization directory are implemented. Campus authentication and campus service adapters are not enabled. Announcement crawling and live Internet Archive compatibility remain unverified.

Build and discover

Use Rust 1.89 or newer on Linux, or the public devcontainer definition. Dependency downloads are public and require no campus credentials.

cargo fetch --locked
cargo build --locked --offline
./target/debug/buaa help
./target/debug/buaa capabilities
./target/debug/buaa schema

Normal commands do not require an interactive prompt. Data goes to JSON/NDJSON stdout; sanitized typed errors go to stderr.

Command examples

Replay local input

printf '[0]first\n[0.25]second\n' | ./target/debug/buaa timed-input

Add --raw for newline-delimited text, or --dry-run to validate and emit the schedule without waiting. The complete input is validated before any event is emitted.

{"type":"timed_input","sequence":1,"at_ns":0,"text":"first"}

Look up an archived page

This is a synthetic URL and a cache-only example; an uncached query returns unavailable rather than inventing history.

printf '%s\n' '{"url":"https://college.example/notice/42.html"}' \
  | ./target/debug/buaa archive lookup

--online explicitly permits authorized archive reads on a cache miss; --refresh conditionally revalidates. Only approved Internet Archive HTTPS routes are allowed. No original campus host is contacted.

Archive query, capture and provenance contracts

List official teaching and research institutions

./target/debug/buaa organizations list

The default reads only a private cache. Explicit --online/--refresh permit the fixed official robots and directory routes. Missing and non-HTTP links stay explicit rather than being guessed.

Account safety

  • One in-flight request; at least five seconds after completion. Background observations are at least fifteen minutes apart.
  • Cache first. Honor Retry-After; a 429 without a valid explicit delay imposes at least thirty minutes.
  • Authentication rejection and challenge signals latch. No automatic login refresh, challenge bypass or fabricated attendance.
  • Every process using an account must share one governed identity and state domain. Worktrees must not create independent limiters.
  • Unknown outcomes, reboot identity mismatch and corrupt history fail closed. Do not delete governor state to regain throughput.
  • Development authorizes no real campus mutation. Future enrolment, evaluation, submission, ticket and destructive-drive operations need preview, typed intent, plan/commit separation and idempotency.

Credentials and private media stay outside public source. The devcontainer build does not copy private HOME, model, GitHub, SSH or Life configuration.

Evidence and limits

The current offline suite passes 54 tests; an ignored worker entry is invoked by the subprocess tests. Strict all-target clippy passes. Independent review findings were reproduced, fixed and re-reviewed.

Capture timestamps are not publication dates. Archive-reported digests are not presented as locally verified resource hashes. Rejected provenance is never committed as an immutable original. Missing history stays missing.

No campus authentication, account mutation, linked-college crawl or live archive observation was performed for this proof. A full devcontainer image build, general Memento crawling, announcement extraction and Life/transcript integration are not claimed complete.
